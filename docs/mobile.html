휴대폰 안에서 실행하는 Cell

1. 지원 브라우저에서 열기

Android는 WebGPU를 지원하는 최신 Chrome, iPhone·iPad는 Safari 26 이상을 우선 사용하세요. 버전 조건만으로 실행을 보장하지 않습니다. Cell의 실제 GPU 감지와 모델 로딩 결과를 확인하세요.

2. 절전 설정으로 시작

Wi-Fi에서 ‘모델 내려받기 · 시작’을 누르세요. 처음에는 수백 MB를 다운로드합니다. 절전 설정은 문맥과 답변 길이를 줄이지만 모델 가중치 자체는 동일합니다. 여유 저장 공간과 GPU 메모리가 필요합니다. 메모리 부족이면 다른 앱을 닫고 다시 시도하거나 본인의 PC에서 사용하세요. 유료 서버로 자동 전환하지 않습니다.

3. 홈 화면에 추가

Android: 설치 버튼이 표시되면 누르거나 Chrome 메뉴의 ‘앱 설치 / 홈 화면에 추가’를 사용하세요. iPhone: Safari 공유 메뉴 → ‘홈 화면에 추가’. 실제 메뉴 이름은 버전에 따라 다릅니다. 설치가 WebGPU 미지원 기기를 지원 기기로 바꾸지는 않습니다.

4. 화면을 열어 두고 대화

앱 전환·화면 잠금 시 모델 작업자를 중지합니다. 돌아오면 다시 시작하세요. 비상 정지도 같은 작업자를 종료합니다. 중지된 답변은 자동 재개하지 않습니다.

데이터와 오프라인

대화는 서버로 전송하거나 동기화하지 않으며 새로고침 시 사라집니다. 앱 화면은 처음 정상 접속 후 캐시합니다. 모델 캐시는 별도로 관리하며 OS가 저장 공간을 회수할 수 있으므로 완전한 오프라인 동작을 보장하지 않습니다. 새 기기의 최초 모델 다운로드에는 인터넷이 필요합니다.

현재 검증 범위

Windows 브라우저 실제 추론과 모바일 너비 화면을 검증했습니다. Android·iOS 실기기 실행은 아직 검증하지 않았습니다. 모델 품질은 시험 단계이며 계산과 사실 관계가 틀릴 수 있습니다. 모바일 OS 전체 접근·자동 학습·백그라운드 상시 실행 기능은 없습니다.

연결 주소

휴대폰에서는 공개 HTTPS 주소로 접속해야 합니다. PC의 127.0.0.1 주소는 휴대폰에서 PC를 가리키지 않습니다. 단순한 PC IP의 HTTP 주소에서는 WebGPU와 설치 기능이 제한될 수 있습니다.
