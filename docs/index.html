A FEW GOOD QUESTIONS

궁금한 점,
솔직한 답.

Cell은 새로운 LLM인가요?＋

아니요. 브라우저 실험판은 사용자 기기에서 무료 공개 모델을 실행하는 대화 프로그램입니다. API 키가 필요하지 않습니다. Cell 자체가 새로운 범용 지능 모델인 것은 아니며, 작은 모델의 품질에는 한계가 있습니다.

‘성장’은 정확히 무슨 뜻인가요?＋

현재의 성장은 경험, 탐색 절차, 검증 근거를 축적하고 재사용하는 것입니다. 모델 가중치를 자동으로 학습하거나 지능 향상을 입증한 단계는 아닙니다. 유용성이 실제로 높아지는지는 동일한 조건의 평가로 확인해야 합니다.

사용하려면 비용이 드나요?＋

브라우저 실험판은 유료 LLM API를 호출하지 않습니다. 최초 모델 다운로드에 데이터와 저장 공간이 필요하며, 추론에는 사용자 기기의 GPU·메모리·전력을 사용합니다. 기존 Windows v0.3 다운로드는 별도 API를 사용하던 이전 버전입니다.

내 대화나 파일이 다른 사람에게 공유되나요?＋

피어 공유는 사용자가 선택한 탐색 절차만 대상으로 합니다. 대화와 개인 파일은 자동으로 공유하지 않습니다. 새 브라우저 대화는 이 탭에서 추론하고 서버에 대화를 저장하지 않습니다. 기존 Windows v0.3의 외부 API 모드에서는 입력이 해당 API로 전달됩니다. 공유할 절차에 민감한 내용이 없는지 직접 확인해야 합니다.

공격받으면 완전히 복구되나요?＋

현재는 받은 절차 패키지의 손상 여부를 확인하고 원래 피어에서 재수신하는 기능입니다. 운영체제 복구나 바이러스 치료 기능이 아니며, 서명만으로 내용의 정확성이나 안전성이 보장되지는 않습니다.

아무 명령이나 마음대로 실행하나요?＋

기본적으로 명령 실행 전에 승인을 요청하고 시간·호출·자원 한도를 둡니다. 그러나 승인된 명령은 현재 Windows 사용자 권한으로 실행되므로 별도 OS 샌드박스로 보아서는 안 됩니다. 실험용 폴더에서 먼저 사용하세요.
