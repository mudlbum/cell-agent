A FEW GOOD QUESTIONS

궁금한 점,
솔직한 답.

Cell은 새로운 LLM인가요?＋

아니요. 브라우저 실험판은 사용자 기기에서 무료 공개 모델을 실행하는 대화 프로그램입니다. API 키가 필요하지 않습니다. Cell 자체가 새로운 범용 지능 모델인 것은 아니며, 작은 모델의 품질에는 한계가 있습니다.

‘성장’은 정확히 무슨 뜻인가요?＋

현재의 성장은 경험, 탐색 절차, 검증 근거를 축적하고 재사용하는 것입니다. 언어 표현의 소규모 LoRA 학습 실험도 시작했지만 대화 개선을 입증하지 못해 실사용 모델에 적용하지 않았습니다. 유용성이 실제로 높아지는지는 동일한 조건의 평가로 확인해야 합니다.

사용하려면 비용이 드나요?＋

브라우저 실험판은 유료 LLM API를 호출하지 않습니다. 최초 모델 다운로드에 데이터와 저장 공간이 필요하며, 추론에는 사용자 기기의 GPU·메모리·전력을 사용합니다. Windows v0.5도 무료 로컬 모델을 사용하며 API 키가 필요하지 않습니다.

내 대화나 파일이 다른 사람에게 공유되나요?＋

피어 공유는 사용자가 선택한 탐색 절차만 대상으로 합니다. 대화와 개인 파일은 자동으로 공유하지 않습니다. 새 브라우저 대화는 이 탭에서 추론하고 서버에 대화를 저장하지 않습니다. Windows v0.5는 PC의 로컬 모델에 입력을 전달하며 유료 외부 모델 호출을 차단합니다. 공유할 절차에 민감한 내용이 없는지 직접 확인해야 합니다.

공격받으면 완전히 복구되나요?＋

현재는 받은 절차 패키지의 손상 여부를 확인하고 원래 피어에서 재수신하는 기능입니다. 운영체제 복구나 바이러스 치료 기능이 아니며, 서명만으로 내용의 정확성이나 안전성이 보장되지는 않습니다.

아무 명령이나 마음대로 실행하나요?＋

현재 무료 대화와 자율 감독은 임의의 OS 명령이나 코드를 생성해 실행하지 않습니다. 감독 루프의 자동 작업은 채택 자료의 절차 초안 작성, 등록 피어 확인, 등록 주제의 Wikipedia 검색으로 제한됩니다. 일반 도구 분업은 고정 시나리오 데모에서 별도로 시험합니다.
