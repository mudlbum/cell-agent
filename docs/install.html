Semi Cell 수집함 열기 ↗

모델 다운로드 없이 메모·출처 링크·선택한 텍스트 파일을 저장합니다. 자료를 선택해 JSON 묶음을 내보낸 뒤 PC로 옮기세요. 사용자가 지정하지 않은 자료나 다른 앱의 내용은 수집하지 않습니다. 실시간 자동 동기화는 아직 없습니다.

PC · Windows v0.5

무료 모델 지원 PC 소스 ZIP 받기 ↓

  1. Python 3.10 이상을 설치하고 ZIP을 새 폴더에 풉니다.
  2. 수집 자료만 관리하려면 control.cmd를 실행합니다. ‘기억과 경로 → Semi Cell 수신함’에서 JSON 파일을 가져오고 각 항목을 검토해 채택합니다. 모델이나 API 키가 필요 없습니다.
  3. AI 대화도 사용하려면 start-free-model.cmd를 실행합니다. 최초 실행은 공식 배포처에서 무료 모델과 실행 파일을 다운로드하고 SHA-256을 확인합니다. 모델 약 429 MB와 런타임 저장 공간·인터넷이 필요합니다.
  4. 모델 콘솔을 켜 둔 상태에서 control.cmd의 ‘무료 로컬 대화’를 사용합니다. 이후 모델 파일이 있으면 외부 LLM 서비스 없이 PC에서 계산합니다.

모델 서버와 Cell 제어창은 별도 프로세스입니다. 모델까지 완전히 끝내려면 모델 콘솔에서 Ctrl+C를 누르세요. Cell의 비상 정지는 Cell 작업자를 종료합니다. 모델 품질은 실험 단계이며 틀린 답을 낼 수 있습니다.

자율 탐색과 검색 후 대화

‘기억과 경로’에서 공개 주제를 등록하면 PC 실행 중 하루 1회 Wikipedia 검색 경로를 수집합니다. 등록한 주제만 외부에 전송합니다. 대화 실행 방식에서 ‘검색 후 대화’를 선택하면 검색 출처와 함께 무료 로컬 모델의 응답을 받을 수 있습니다. 자동 검색은 인터넷 전체가 아닌 Wikipedia 범위입니다. 후보는 검토 후 사용하세요.

언어 학습 실험의 재현 방법과 첫 결과는 ZIP의 LEARNING.ko.md에 있습니다. 일반 사용자에게 별도 학습 환경 설치를 요구하지 않습니다.

브라우저 자체 AI · 선택 기능

무료 브라우저 대화 열기 ↗

WebGPU를 지원하는 기기에서는 무료 공개 모델을 브라우저에서 직접 실행할 수 있습니다. 모바일은 절전 설정을 사용하세요. Semi Cell 수집에는 이 기능이 필요하지 않습니다.

현재 지원 범위

Windows PC 수신함·무료 대화는 로컬 검증했습니다. macOS의 PC 감독 프로그램은 아직 이식되지 않았습니다. Semi Cell은 모바일 브라우저용으로 구현했지만 실제 갤럭시 S21 울트라와 iPhone 검증은 아직 남아 있습니다. APK·App Store 설치 앱은 제공하지 않습니다.

자료와 권한

Semi Cell 자료는 IndexedDB에 저장하며 사용자가 내보내기 전에는 PC나 서버로 보내지 않습니다. 브라우저 데이터 삭제 시 사라질 수 있습니다. PC는 받은 자료를 격리하고 검토 후 ‘미검증 자료’ 기억에 추가합니다. 링크를 자동으로 방문하거나 자료 속 명령을 실행하지 않습니다. 언어 학습은 별도 실험 도구이며 실사용 모델을 자동 교체하지 않습니다. 자가 코드 수정·무제한 OS 제어는 구현되지 않았습니다.

독립 실행의 의미

OpenAI·Claude·Gemini 계정이나 유료 API 키가 필요하지 않습니다. AI 대화에는 무료 공개 모델이 필요하고, 최초 모델 다운로드와 프로그램 배포에는 인터넷을 사용합니다. 운영체제·Python·브라우저와 같은 실행 환경까지 없앨 수 있는 것은 아닙니다.

현재 다운로드는 v0.5입니다. 이전 v0.3의 API 설정 안내는 새 버전에 적용되지 않습니다.
