GETTING STARTED / V0.3

작게 시작하는
나의 첫 Cell.

먼저 오프라인 데모로 작업 흐름과 중단 기능을 확인하세요.
준비되면 API 키를 연결해 실제 질문과 작업을 맡길 수 있습니다.

이 배포본은 개발 초기 Windows 실험판입니다. Python 소스 패키지이며 설치형 EXE나 모바일 앱이 아닙니다. 중요한 원본 대신 별도의 실험용 폴더에서 시작하는 것을 권장합니다.

Windows에서 시작하기

1. Python을 준비하세요

Python 공식 다운로드에서 Python 3.10 이상을 설치하세요. 설치 화면에 경로 등록 옵션이 있으면 선택합니다. 터미널에서 다음 명령이 버전을 출력하는지 확인하세요.

python --version

현재 검증 환경은 Windows, Python 3.10.10입니다. 다른 Windows·Python 버전은 별도 검증이 필요할 수 있습니다.

2. Cell을 내려받고 압축을 푸세요

Cell v0.3 다운로드 ↓

ZIP 파일을 문서 폴더 등 쓰기 가능한 위치에 풀어 주세요. 폴더 안의 control.cmd를 실행하면 제어 서버와 브라우저 화면이 열립니다. 터미널에서 직접 실행해도 됩니다.

python -X utf8 dashboard.py

자동으로 열린 주소에는 이 컴퓨터의 제어 세션 토큰이 들어 있습니다. 이 주소를 다른 사람에게 공유하지 마세요. 서버를 실행한 창을 닫으면 진행 중인 작업도 종료됩니다.

3. API 키 없이 먼저 체험하세요

  1. 대화창의 모델 선택에서 고정 시나리오 데모를 고릅니다.
  2. 메시지를 입력하고 보내기를 누릅니다.
  3. 세포가 역할을 나누고 예제 파일을 생성하는 흐름을 봅니다. 명령 요청이 나타나면 내용을 확인해 승인하거나 거절합니다.
  4. 상단의 비상 정지로 작업을 멈출 수 있습니다. 정지 후 새 작업을 시작하려면 잠금을 직접 해제합니다.

데모는 입력한 질문에 답하는 AI가 아닙니다. 미리 정해진 파일 생성·검사 과정을 보여 줍니다.

4. 실제 AI를 연결하세요

  1. 대화 화면의 모델 연결과 설정을 펼칩니다.
  2. OpenAI API 키를 로컬 화면에 입력하고 적용합니다. 키는 감독 서버의 메모리에만 보관합니다.
  3. GPT-6 Astra를 선택하고 질문하거나 작업을 맡깁니다.
  4. 명령 실행 요청은 내용과 작업 위치를 확인한 뒤 승인합니다.

API 사용 요금은 사용자의 API 계정에 청구될 수 있습니다. 해당 모델에 접근 가능한 계정이 필요합니다. API 키나 민감한 문서를 공개 저장소에 올리지 마세요. 이 배포 과정에서는 실제 유료 모델 호출을 검증하지 않았습니다.

5. 탐색 절차를 다른 컴퓨터와 공유하려면

공유는 선택 기능입니다. 먼저 아래 의존성을 설치하세요.

python -m pip install -r requirements-network.txt

‘기억과 경로’에서 검증한 절차를 선택해 공유 피드에 추가합니다. 공유 서버는 대화 서버와 별도로 실행합니다.

python share_server.py

기본 주소는 http://127.0.0.1:8766이며 자기 컴퓨터에서만 접근할 수 있습니다. 다른 컴퓨터가 가져가려면 읽기 전용 피드에 HTTPS 주소를 제공하는 별도 구성이 필요합니다. 대화·명령 제어 서버인 8765 포트는 공개하지 마세요.

상대와 별도 채널로 공개 키의 지문을 확인한 뒤 ‘연결과 공유’에 HTTPS 주소와 공개 키를 등록합니다. 가져온 절차는 격리 보관 → 후보 등록 → 로컬 검증을 거칩니다. 서명은 발신자를 확인하는 수단이며 내용의 안전성을 보장하지 않습니다.

네 가지 환경, 같은 방향

목표는 어디서나 대화하고, 필요한 기기의 허용된 작업을 맡기는 것입니다. 현재 지원과 계획을 구분해 공개합니다.

환경현재 상태다음 구현
WindowsPython 실험판독립 설치 파일·서명·업데이트 검증
macOS실행판 미지원프로세스 감독·권한 처리·서명·공증·기기 검증
Android앱 미출시대화·파일 선택·PC 작업 제어 컴패니언
iOS앱 미출시모바일 권한·백그라운드 정책에 맞춘 컴패니언
웹반응형 소개·설치 안내인증·암호화된 원격 대화 및 기기 연결

휴대폰의 앱 권한과 백그라운드 실행은 PC와 다릅니다. 모바일에 PC 전체 제어와 같은 권한을 약속하지 않습니다. 장시간 작업은 명시적으로 연결한 PC나 서버가 수행하고, 휴대폰은 요청·승인·결과 확인을 맡도록 설계할 계획입니다.

Apple의 백그라운드 실행 안내 ↗

데이터와 권한

  • 로컬 저장: 대화, 작업 이벤트, 경험, 파일 변경 백업은 설치 폴더의 상태 디렉터리에 저장됩니다. 현재 저장 데이터 자체의 암호화 기능은 없습니다.
  • 모델 API: 실제 실행 시 메시지, 최근 대화, 필요한 파일 내용과 도구 결과가 API로 전달될 수 있습니다. 제공자의 데이터 처리 정책이 적용됩니다.
  • 피어 공유: 선택한 탐색 절차만 피드에 게시합니다. 이미 다른 컴퓨터가 가져간 내용은 게시 취소만으로 회수할 수 없습니다.
  • 명령 권한: 승인된 명령은 현재 Windows 사용자 권한으로 실행됩니다. 파일 도구의 경로 제한이 명령 실행 전체를 격리하지는 않습니다.
  • 비상 정지: 감독 프로세스가 로컬 작업 그룹을 종료합니다. 이미 발생한 변경이나 외부 API 요청은 취소·복구되지 않을 수 있습니다.

이 홈페이지에는 광고나 분석 스크립트를 넣지 않았습니다. 웹 폰트는 Google Fonts에서 로드하며, 호스팅 사업자는 일반 접속 기록을 처리할 수 있습니다. 홈페이지의 체험 버튼은 실제 AI나 사용자 컴퓨터의 에이전트를 실행하지 않습니다.

문제가 생겼나요?

브라우저가 열리지 않을 때

실행 창에 출력된 전체 시작 주소를 복사해 같은 컴퓨터의 브라우저에서 여세요. 세션 토큰이 빠지면 연결 인증이 실패할 수 있습니다.

실행 잠금 표시가 있을 때

직전 작업의 상태를 확인하고 상단 ‘잠금 해제’에서 RESUME을 입력하세요. 정지한 작업이 자동으로 재개되는 것은 아닙니다.

모델 연결 오류가 발생할 때

API 키, 계정의 모델 접근 권한, 요금 한도, 인터넷 연결을 확인하세요. 키와 전체 민감한 요청 본문을 오류 제보에 포함하지 마세요.
