# Cell v0.5 — API 키 없는 PC Cell과 Semi Cell 수신함

OpenAI/Claude/Gemini 계정과 유료 LLM API를 사용하지 않습니다. 이전 GPT API 어댑터는 호출 전에 차단됩니다. 현재 AI 대화는 무료 공개 모델입니다. 언어 표현의 LoRA 학습은 별도 제한된 실험 도구로 제공하며, 후보가 실사용 모델에 자동 적용되지는 않습니다. [학습 실험과 첫 결과](LEARNING.ko.md)를 참고하세요.

## Windows 실행
Python 3.10 이상에서 ZIP을 풉니다.
- 자료 관리: control.cmd. 기억과 경로 → Semi Cell 수신함에서 모바일 JSON을 선택합니다.
- 무료 AI 대화: 먼저 start-free-model.cmd 실행. 최초에 공식 llama.cpp CPU 런타임과 Qwen3-0.6B Q4_0 모델을 다운로드하며 해시를 검증합니다. 모델 서버를 켜 둔 채 control.cmd → 무료 로컬 대화를 사용합니다.
- 첫 설치 후 같은 파일이 있으면 모델 다운로드를 반복하지 않습니다. 모델/런타임은 local-model 폴더에 저장합니다. 모델은 약 429 MB이며 런타임 ZIP과 압축 해제 공간이 추가로 필요합니다.
- 모델 서버 포트 8081, 제어 포트 8765는 127.0.0.1에만 바인딩합니다. 인터넷에 포트를 공개하지 마세요.
- 두 콘솔은 별개입니다. Cell 비상 정지는 작업자를 종료합니다. 모델 서버도 끝내려면 모델 콘솔에서 Ctrl+C를 누릅니다.

## Semi Cell 흐름
https://mudlbum.github.io/cell-agent/semi.html
모바일에서 직접 선택한 메모/링크/6 KB 이내 텍스트를 저장 → 항목 선택 → 내용 검토 → JSON 파일 저장 → 직접 PC로 옮기기 → 수신함 가져오기 → 격리 → 항목별 검토 근거와 채택/거절.

한 묶음 45 KB/50개, PC 수신함 300개 한도. 같은 ID/내용의 재수신은 중복 처리하고 같은 ID의 다른 내용은 묶음 전체를 거부합니다. 수신 항목의 출처 신원이나 정확성을 검증한 서명 프로토콜은 아닙니다. 채택한 자료는 hypothesis 기억으로 저장합니다. 자료와 링크를 자동 실행/방문하지 않습니다. 파일 이름을 PC 경로로 사용하지 않습니다. 실시간 네트워크 동기화는 미구현입니다.

## 실행 범위
- 무료 로컬 대화: 글/코드 초안과 질문 답변. 파일·명령 도구 없음. 선택한 검색 후 대화 모드는 Wikipedia 검색어(120자)를 외부에 전송하고 조회 출처를 표시함. 작은 모델은 계산과 한국어에서 오답이 나올 수 있음.
- 고정 시나리오 데모: 분업·도구·제어를 시험하는 고정 코드이며 일반 자율 AI가 아님.
- Semi Cell: LLM 없이 수집·저장·내보내기/PC 검토·기억 반영.
- 피어 절차 공유: 기존 선택적 네트워크 기능. 자동 바이러스 치료/OS 복구가 아님.
- Windows 감독 코드는 macOS에서 미지원. 모바일 Semi Cell은 웹 구현이며 실기기 검증 필요.

## 검증
python -X utf8 -m unittest discover -p "test_*.py" -q

최초 모델/프로그램 설치에는 인터넷을 사용합니다. 모든 작업이 인터넷 없이 가능한 것은 아니지만 유료 외부 LLM 호출은 필요하지 않습니다. 가입/동기화/장치 인증과 자동 분산 학습은 구현되지 않았습니다.

## 상시 자율 감독
PC 프로그램 실행 중 5초마다 새 작업을 확인합니다. 채택된 Semi 자료는 절차 후보를 생성하고, 등록 피어는 15분 간격, 등록 공개 검색 주제는 하루 간격으로 조회합니다. 모든 후보는 검토 전 상태입니다. 관제실 탭을 닫아도 감독은 계속되며 비상 정지는 새 작업도 막습니다. OS 시작 시 자동 실행은 아직 없습니다. 인터넷 전체 자동 기기 발견·중계 서버는 운영하지 않습니다.
