로컬 모델 연결 안내

로컬 모델 서버: 127.0.0.1:8081. 유료 외부 API 전환은 차단했습니다. 일반 대화는 글·코드 초안 작성용입니다. 검색 후 대화는 입력한 검색어(120자 이내)를 Wikipedia에 보내고 출처를 함께 표시합니다. 개인 정보는 검색어에 넣지 마세요. 파일·명령 도구는 실행하지 않습니다. 질문은 UTF-8 1,800바이트까지, 이전 대화는 최근 12개 중 총 2,200바이트 예산에 들어가는 부분만 전달합니다. 오래된 내용을 잊을 수 있습니다. 로컬 모델 서버는 별도 프로세스이며 비상 정지는 Cell 작업자를 종료합니다.

상시 자율 감독

PC 제어 프로그램이 켜져 있으면 5초마다 새 과제를 확인합니다. 채택 자료는 무료 로컬 모델로 절차 후보를 만들고, 등록한 피어는 15분 간격으로 새 서명 자료를 확인합니다. 새 후보는 자동 활성화하지 않습니다. 이 작업은 관제실 탭을 닫아도 계속됩니다. 비상 정지는 감독 루프의 새 실행도 막습니다.

등록한 공개 주제는 하루 1회 Wikipedia에서 탐색 경로를 수집합니다. 검색 결과는 검증 전 후보이며, 가중치 학습이 아닙니다.
