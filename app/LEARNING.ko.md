# Cell 언어·검색 개선 실험

현재 Cell은 새로 만든 기반 LLM이 아니라 무료 공개 Qwen3-0.6B를 실행한다. 목표는 언어 표현을 작은 보정 파일로 개선하고, 새로운 사실은 조회하며, 검토한 탐색 방법을 공유하는 것이다. 범용 지능과 지속적인 품질 향상은 아직 입증하지 않았다.

## 서로 다른 세 가지 루프

1. **사용 루프**: 사용자 요청 → 로컬 대화 또는 검색 후 대화 → 실제 출처·실행 기록 → 사용자 평가. 검색 후 대화는 Wikipedia 검색어만 전송한다. 현재 자동 Google 검색, 인터넷 전체 탐색, 임의 OS 작업은 지원하지 않는다.
2. **탐색 루프**: 기억과 경로에서 공개 주제 등록 → PC가 켜져 있고 유휴 상태일 때 하루 1회 검색 → 출처와 재검색 방법을 후보로 저장 → 검토 → 선택적 피어 공유. 받은 후보는 로컬에서 다시 검증한다. 결과 없음·실패는 성공으로 간주하지 않으며 재시도에는 간격을 둔다. 등록 주제 10개, 한 조회 결과 3개, 128KB 응답 제한. 비상 정지는 이 감독 루프를 중단한다.
3. **언어 학습 루프**: 공개 기반 모델의 고정 버전 + 직접 작성한 합성 대화 예문 → LoRA 후보 학습 → 학습에 쓰지 않은 예문으로 비교 → 생성 응답 검토 → 후보 유지/기각. 배포 모델과 가중치를 자동으로 교체하지 않는다. 개인 대화, 검색 본문, 다른 Cell 패키지를 자동으로 학습하지 않는다.

## 첫 실제 실험 — 2026-09-19

- 기본 모델: Qwen/Qwen3-0.6B, revision c1899de289a04d12100db370d81485cdf75e47ca, Apache-2.0.
- CPU float32, LoRA rank 4, q_proj/v_proj, 학습 대상 573,440개 파라미터.
- 직접 작성한 합성 학습 예문 16개, 별도 평가 예문 6개, 16단계, seed 42.
- 평균 평가 손실: 2.6861319 → 2.6176361 (약 2.55% 감소).
- 사전 설정한 최소 3% 감소 조건에는 미달. 생성한 두 응답도 전후 동일했고, 빠진 문장을 요청하는 시험에서 부자연스러운 응답이 유지됨.
- 결과: **candidate_not_deployed**. 대화 능력이 향상되었다는 증거로 간주하지 않음.
- 후보 가중치 파일 약 2.3MB. 학습 프로세스 최대 커밋 메모리 약 7.13GB. 기본 학습용 모델·Python 라이브러리는 별도 GB 단위 공간 필요.
- 이 평가는 작고 한국어 중심이므로 보지 못한 대화·다중 턴·영어·검색 판단·기존 능력 손실을 더 평가해야 함. 평가 예문을 학습으로 옮기지 말 것.

## 실험 재현 (Windows 전용 감독)

별도 가상환경에 torch 2.8.0 CPU, transformers 4.57.1, peft 0.17.1을 설치한다. torch 공식 CPU 인덱스와 PyPI를 사용한다. 일반 Cell 사용에는 이 대용량 학습 환경이 필요 없다.

```powershell
python -m venv training-venv
training-venv/Scripts/python.exe -m pip install --upgrade pip
training-venv/Scripts/python.exe -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu
training-venv/Scripts/python.exe -m pip install transformers==4.57.1 peft==0.17.1
training-venv/Scripts/python.exe -X utf8 train_language.py --output learning/run-001 --cache training-cache --steps 16 --minutes 20
```

Windows Job Object로 CPU 25%, RAM 12GB, 실행시간 최대 20분을 제한한다. 다운로드도 시간 예산에 포함한다. 작업 중 `learning/STOP` 빈 파일을 만들거나 부모 프로세스에 Ctrl+C를 보내면 중단한다. STOP 파일은 명시적으로 지워야 재개된다. 중복 실행은 training.lock으로 거부한다. 예기치 않은 종료로 잠금 파일이 남으면 프로세스 종료 여부를 확인한 뒤 잠금만 정리한다.

**학습은 PC 관제실 밖에서 실행하는 별도 실험이다. 현재 PC 앱 비상 정지는 이 학습 프로세스나 별도 모델 서버를 종료하지 않는다.** 예약 학습을 멈추려면 Codex 예약을 끄고 실험 디렉터리 부모의 STOP 파일을 사용한다. 이 작업 공간의 STOP 위치는 outputs/cell-learning/STOP이다.

## 예약 운영

이 작업 공간에는 Codex 예약 `cell-7`이 2026-09-20~26, America/Toronto 04:00에 하루 1회 실행하도록 등록됐다. 배포 ZIP을 설치한 사람에게 이 Codex 예약이 복제되는 것은 아니다. PC/앱의 실행 상태에 따라 예약은 수행되지 않을 수 있다.

한 회차는 이전 실패를 분석하고 하나의 변경만 시험한다. 최대 16단계·20분이며 유료 모델 호출과 자동 배포는 금지한다. 기본 모델을 계속 덮어쓰며 학습하지 않고, 고정 기준 모델에서 후보를 비교하여 회귀를 추적한다. 여러 회차 결과만으로 AGI라고 선언하지 않는다.

## 공동 성장의 구현 범위와 다음 단계

지금 공유되는 것은 사용자가 검토 후 선택한 서명된 탐색 절차다. 피어를 등록한 Cell끼리 새 패키지를 주기적으로 조회하고 격리한다. 가중치 평균화, 자동 어댑터 배포, 인터넷 전체 기기 자동 발견은 미구현이다.

다음 단계는 (1) 실제 다중 턴 대화 평가 확대, (2) 공통 테스트와 출처를 포함한 개선 제안 패키지, (3) 호환 모델·토크나이저·버전 확인, (4) 수신 기기에서 재평가, (5) 명시적 활성화와 이전 버전 복귀다. 모델과 토크나이저가 다른 기기의 어댑터를 무조건 합치지 않는다. 서명은 발신자 확인이며 품질 보증이 아니다. 공개 중계/장치 발견 서버는 아직 운영하지 않는다.
